# airplantnina — Brand Knowledge Base

This folder is the agent's memory of **who airplantnina is and how Nina sounds.**
Every skill reads everything in here before it writes a single word, so the
outreach always sounds like Nina — not like AI, and not like a template.

## How to teach the agent more (drop files in here)
The agent reads **every file in this folder.** To make it smarter about your
brand, just add files — no code, no setup:
- An About page, a press article, a podcast transcript
- Your best Instagram captions
- Real customer reviews or testimonials
- A new product line sheet

More truth in this folder = more personal, more on-voice outreach.

## To change how you sound
Edit **voice.md**. That file is the single source of truth for tone. Change it,
and every future message changes with it.

## What's in here
- `voice.md` — how Nina sounds (edit this to tune the voice)
- `product.md` — what the pieces are + plant care facts
- `positioning.md` — where airplantnina sits in the market
- `industry_agreements_research.md` — standard wholesale/gifting terms
- `sample_outreach_*.md`, `sample_*_agreement.md` — reference examples

> This is also the product story: change `voice.md` + the brand files, and the
> same agent runs for any other independent designer. One engine, any brand.
